## ⚡ الميزات الرئيسية (Key Features)

* **🎨 تصميم عصري وتفاعلي:** واجهة مستخدم مظلمة (Dark Theme) بطابع سيبراني مع تأثيرات حركة سلسة.
* **📱 متجاوب تماماً (Responsive):** تصميم متوافق مع كافة الشاشات والأنظمة.
* **🌐 دعم ثنائي اللغة:** إمكانية التصفح باللغتين العربية والإنجليزية.
* **🚀 استعراض المشاريع:** عرض للمشاريع التطبيقية مثل **Dara' Unified Cyber Defense** و **Sanad AI**.
