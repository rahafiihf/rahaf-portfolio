# Rahaf's Digital Chronicle (88)

Create a visually stunning, bilingual (Arabic and English) personal portfolio website for Rahaf Hamdan Alshaibani, a 22-year-old cybersecurity student. 
 
The concept should be storytelling-based, presenting my personal journey in technology as a timeline (past to present), not focusing on the future. 
 
The design should combine a historical storytelling style with modern tech aesthetics: dark theme, elegant sections, smooth animations, and a clean professional look. 
 
The website must support both Arabic (RTL) and English (LTR) with a language toggle button. 
 
Sections: 
 1. Hero Section: 
Display the name “Rahaf Hamdan Alshaibani” and title “Cybersecurity Student & Programmer”. 
Add a tagline: “My journey in technology and cybersecurity.” 
Include a typing animation. 
 2. My Journey Timeline (Main Feature): 
Create a timeline that tells my story: 
 
 • Beginning of my interest in technology 
 • Studying programming at Princess Nourah University 
 • Developing my skills 
 • Currently studying cybersecurity at Imam University 
 
 3. About Me (Arabic & English): 
I am a programming graduate from Princess Nourah University and currently studying cybersecurity at Imam University. 
I am passionate about technology, always curious, and love learning and improving my skills. 
 4. Skills Section: 
HTML, CSS, JavaScript, Programming Basics, Cybersecurity Fundamentals 
Display them in a modern way (progress bars or icons). 
 5. Projects Section: 
Show 2–3 simple projects in clean cards. 
 6. Contact Section: 
Include: 
Email: ruiiihf@gmail.com 
Phone: 0501780242 
LinkedIn: https://www.linkedin.com/in/rahaf-alshaibani-bb3001329 
 
Make LinkedIn clickable and add icons. 
 
Add smooth scrolling, hover effects, and storytelling feel throughout the site 
In the Projects section, create 3 realistic and professional projects. 
Each project should have: 
 • A title 
 • A short description 
 • A small story behind the project (why it was created, what problem it solves) 
 • A “View Project” button that opens a detailed page or modal 
 
Each project story should feel personal, realistic, and written from the perspective of a passionate cybersecurity student. 
 
The projects should be simple but meaningful, such as: 
 • Personal Portfolio Website 
 • Security Awareness Website 
 • Simple Web Tool 
 
When clicking on a project, show more details including: 
 • The idea 
 • What I learned 
 • Tools used (HTML, CSS, JavaScript) 
 
Make the design modern, clean, and engaging 
Each project must include a written story that appears when the project is opened. 
The story should be written in first-person, emotional and realistic, as if I personally created the project. 
It should describe: 
 • Why I started the project 
 • What challenge I faced 
 • What I learned 
 
The story should be engaging, human, and not robotic. 
Also provide the story in both Arabic and English.
